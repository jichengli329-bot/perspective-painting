# 第三大周期：第一关美术标杆重制

## 结论

本周期暂停扩展玩法和关卡数量，只重制第一关“雾谷石桥”。目标是建立一套可以复用于整部游戏的商业级美术管线，并让第一张静态截图具备商店页展示质量。

视觉定位锁定为：

> 宋画青绿山水 × 桌面微缩盆景 × 温润陶瓷玩具

“精致”不等于写实或堆面数。本项目的精致感来自统一的造型语言、清楚的空间层次、准确的比例、克制的材质、稳定的光影和完整的交互反馈。

## 一、周期目标

1. 第一关从任何主要镜头看都不再出现可识别的默认圆锥、胶囊体或裸基础几何体。
2. 山、桥、亭、树、岩石五类核心资产形成统一、可复用的美术套件。
3. 远景、中景、前景在实体操作台上无需文字说明也能被看懂。
4. 玩家能通过格线、底座、接触阴影和模型比例判断横向位置与深度层。
5. 目标画面仍像一幅完整山水画，操作视角则像一件收藏级桌面装置。
6. 评分继续依赖 Object-ID 与轮廓，不因材质、灯光或后处理变化而失效。
7. 最终 Windows 候选版保留现有拖拽、吸附、提示、撤销和通关流程。

## 二、明确不做

- 不同时重做四关。
- 不增加剧情、人物、联网、关卡编辑器或正式音频系统。
- 不追求写实 PBR、电影级植被或高成本角色动画。
- 不用大量来源不一的素材包拼成不统一的画面。
- 不以提高模型面数替代轮廓、比例和构图设计。
- 不让美术网格直接承担精确点击和碰撞；交互继续使用独立简化碰撞体。

## 三、美术硬规范

### 3.1 造型语言

- 所有硬表面具有柔和倒角或手工削切感。
- 山体使用不对称山脊、层叠岩面、坡肩和局部金线，不再使用单一圆锥轮廓。
- 建筑使用略夸张的屋檐、栏杆、柱础和桥拱，使缩略图中仍可辨认。
- 树冠使用 2–4 层不规则团块与可见枝干，避免球体堆叠。
- 每件可操作物都有自然融入造型的占地底座或接地轮廓。

### 3.2 比例与画面占用

- 主要可操作模型相对当前版本放大约 20%–40%，最终以镜头审查为准。
- 操作台有效区域应占左侧游戏视图的主体，不保留无意义的大块空白。
- 桥和亭必须在 320×180 缩略图中一眼可辨。
- 山体之间必须存在明显的高度、宽度和山脊差异。

### 3.3 材质与色板

- 主材质：低反射温润陶瓷，保留柔和宽高光。
- 山体：青绿、浅玉、墨绿三个明度层；阴面偏蓝灰，边缘可有克制金线。
- 木构：深胡桃木；屋顶：低饱和青玉；桥体：暖石色。
- 操作台：暖象牙石材与低饱和水色，不使用纯白或高饱和调试色。
- 每件模型最多 3–4 个主要材质区域，避免视觉噪声。

### 3.4 光影

- 一个宽柔主光负责体积，一个弱冷补光保留阴面层次。
- 接触阴影和环境遮蔽必须清楚表达“模型落在哪一层”。
- 水面只保留轻微渐变、菲涅尔和缓慢纹理，不制造强镜面反射。
- 雾用于分离远近层，不遮挡交互对象轮廓。
- 后处理保持克制：轻微色调映射、环境遮蔽和极弱辉光，不使用重晕影与色差。

## 四、空间可读性重构

美术和操作必须共同解决深度难判断的问题。

1. 操作台固定显示五列、三层的实体构图棋盘。
2. 横向格线融入石板缝、水纹或镶嵌金线，不表现为开发调试线。
3. 三个深度层采用细微色差、边界线和 2–4 厘米等效高度差区分。
4. 远、中、近标识位于台面边缘，选中时加强，未选中时仍然可读。
5. 模型下方显示半透明占地投影；拖动时高亮当前格，其他格保持克制。
6. 滚轮切层时，模型沿一条短弧线落到相邻层，并显示一次清楚的层名反馈。
7. 增加按住空格的临时高角度观察，不允许自由相机；松开后返回主构建镜头。
8. 第一关直接展示推荐深度层，后续关卡再逐渐减少该信息。

## 五、内部执行阶段

### A. 概念标杆与资产清单

- 以现有第一关构图为约束，制作 4 张同构图视觉方案：陶瓷青绿、纸雕山水、木质盆景、玉石博物馆。
- 从可读性、辨识度、制作成本和传播截图四项评分，只选择一个方向。
- 输出正面目标画、三分之四操作视角、材质近景和色板。
- 将最终概念图作为后续所有实现的视觉真值，不在代码阶段重新争论风格。

硬门槛 A：缩小到 320×180 后，桥、亭、主山和远山仍能被独立辨认；操作视角看起来像完整产品而非 Unity 原型。

### B. 可复用英雄资产套件

- 重做三种山体轮廓，并拆出岩面、山脊高光与金线装饰层。
- 重做拱桥：桥拱、桥面、栏杆、柱头和桥基形成连贯结构。
- 重做亭子：基座、柱、梁、双层屋檐、脊饰和台阶正确连接。
- 重做两套树木与三套岩石变体。
- 美术网格、简化碰撞体、评分 ID 根节点三者解耦。
- 将资产生成/导入从总场景构建器中拆出，场景构建器只负责组合与配置。

硬门槛 B：所有资产在纯色材质下仍靠轮廓成立；任何主模型不得呈现默认 Primitive 观感。

### C. 材质与 Shader 基线

- 将现有 `ToyLit` 升级为统一的陶瓷青绿材质基线。
- 支持可控的明暗分段、柔和高光、边缘光、顶到底渐变和局部金线遮罩。
- 山体、建筑、树木只通过参数实例形成变化，不复制多套不可维护 Shader。
- 为 Object-ID 渲染保留独立稳定通道，视觉 Shader 不得污染评分颜色。

硬门槛 C：在主光旋转 30° 的情况下仍保持清楚体积，不依赖后处理掩盖模型问题。

### D. 棋盘、镜头与空间表达

- 重做操作台比例和三层实体棋盘。
- 接入占地投影、当前格、深度层切换动画和临时高角度观察。
- 放大模型并重新标定碰撞体、吸附点、软边界和摄像机构图。
- 目标画、当前画与操作台保持清楚的信息层级。

硬门槛 D：关闭所有文字提示后，观察者仍能指出三个深度层，并能预测一次滚轮操作会把模型移动到哪里。

### E. 第一关完整美术整合

- 用新资产重建“雾谷石桥”的隐藏标准解和初始布局。
- 重新生成 Beauty、Object-ID 与 Silhouette 参考图。
- 调整灯光、雾、水面、背景、UI 边框和完成揭晓。
- 保持第一关只操作桥和亭，确保美术提升没有重新增加教学难度。
- 对 16:9、16:10、超宽和窗口模式进行画面审查。

硬门槛 E：第一张截图可以不加解释直接作为商店页素材；20 秒录屏能表达“立体摆件变成山水画”的核心惊喜。

### F. 回归与候选构建

- EditMode：网格生成、材质配置、评分数据和模型边界测试。
- PlayMode：点击、拖动、吸附、切层、撤销、重置、提示、辅助摆放与完成揭晓。
- 自动捕获正面目标、初始操作视角、完成操作视角、通关揭晓四张审查图。
- 完成 Windows Development Build 与独立进程冒烟。
- 只交付一个第一关美术候选版给用户进行最终玩家评测。

## 六、执行顺序与提交边界

至少形成五个可回退提交：

1. `art: lock Mist Valley benchmark direction`
2. `art: build reusable landscape hero kit`
3. `art: establish celadon ceramic material system`
4. `feat: integrate readable three-layer composition board`
5. `release: assemble Mist Valley art benchmark candidate`

每个阶段都先截图审查再进入下一阶段。若概念或资产硬门槛未通过，不以增加 UI、后处理或特效掩盖问题。

## 七、验收问题

最终用户只需要回答：

1. 第一眼是否像一款正式销售的独立游戏？
2. 不看说明，能否看懂横向格与远、中、近三层？
3. 桥、亭、山和树是否具有想拿起来摆弄的质感？
4. 目标画是否像画，而不是模型截图或像素坐标图？
5. 完成揭晓是否值得录屏分享？

前四项至少四项明确为“是”，并且第五项不为“否”，才允许把这套资产扩展到第二至第四关。
