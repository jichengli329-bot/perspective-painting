# Cycle 05：四件英雄资产家族

## 目标

一次性把 Mist Valley 的拱桥、亭子、主山和松树提升为同一套可用于正式游戏的英雄
资产家族。周期内不向玩家交付半成品；四件全部完成、整体构图重新平衡并通过全部
验收后，才生成新的 Windows 候选版。

设计基准：`docs/art-direction/cycle-05/hero-asset-family-reference.png`。

## 统一视觉语言

- 主材质：青瓷釉面；结构面：象牙白陶瓷；承重件：深木；金色仅作节点强调。
- 边缘必须柔和但轮廓明确，避免默认 Primitive 和互相穿插的零件。
- 所有根节点原点仍位于底面中心，视觉网格与简化碰撞体分离。
- 操作视角优先清晰和可选，构图视角优先剪影、遮挡和画面重合。

## 四个内部阶段

1. 拱桥：连续拱腹、完整桥身、可读石阶、连续双侧栏杆、自然桥头连接。
2. 亭子：基台、台阶、四柱、四向檐梁、斗拱暗示、单一完整攒尖屋顶与脊饰。
3. 主山：高低峰群、清楚山脊、台地层次、克制金纹；避免装饰锥体。
4. 松树：连续弯曲树干、真实连接的分枝、层云树冠、稳定视觉底座。

## 硬验收

- 四件都在代码中拥有独立、可重复生成的 V3 资产，而不是在场景里手工拼补。
- 简化碰撞体与原有操作范围不变，第一关难度不因外观升级而上升。
- 固定操作镜头和构图镜头均人工审查，Object-ID 和轮廓目标重新生成。
- 视觉回归的有意变化更新基线，其余八个镜头不得无解释漂移。
- EditMode、GPU PlayMode、Windows 构建和独立进程冒烟全部通过。

## 非目标

不扩展新关卡、剧情、音频、联网或玩法规则；不为了概念图细节牺牲小屏可读性；
没有外部 DCC 工具时不伪称是手工 Blender 高模，而是完成可替换的生产级程序资产
基线，未来 FBX 可沿 T-027 管线逐件替换。
