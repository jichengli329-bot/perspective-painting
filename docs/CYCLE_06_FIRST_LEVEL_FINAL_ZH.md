# 周期 06：首关产品化封版

## 玩家目标

首关不是考试，而是一次 30–60 秒的“我懂了”体验：先摆拱桥，再摆凉亭，亲眼看到二维画面如何由三维景物重合而成。

## 交互契约

- 第一步只有拱桥可操作；凉亭保持可见，但暂不可拾取。
- 拱桥达到视觉诊断的“已成立”后，第二步自动开放凉亭。
- 解锁依据是最终画面诊断，不比较作者内部坐标，等价构图仍可通过。
- 常驻中文提示同时说明当前步骤、移动方向和前景/中景/远景层。
- 自动吸附、撤销、目标轮廓、对照与辅助摆放继续保留。

## 完成揭晓

输入锁定后，镜头先进入目标画视角并确认“画面重合”，短暂停留，再平滑拉回三维展台，明确揭示不同深度共同组成一幅画。

## 本地验证数据

仅在本机 `Application.persistentDataPath` 写入最近一次会话 JSON：耗时、各物体拾取/落位次数、无效落位次数，以及 H/G/R/Tab/Space 的使用次数。不得包含姓名、设备标识、路径、网络地址或上传逻辑。
